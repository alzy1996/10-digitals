# Dallni v0.3 "Toy World" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the default 3D look a lit, soft-shadowed "Bright Toy Game" world with a matching bright game UI. Add an
automatic quality level, while the storm and classic looks keep working.

**Architecture:**
- A third scene style, `toy`, rides the existing palette and colour-key registry (`palette.js`), with its own lit
  material set (Lambert) and a light rig in `engine.js`.
- Bevels are a MeshBuilder option, so toy geometry is rebuilt when the style family changes.
- Quality selection is a pure function outside `src/engine`, so the first-screen bundle does not pull in the 3D chunk.
- The UI is re-valued in place (CSS tokens + hard-coded colours) so the first-screen CSS does not grow.

**Tech Stack:** three.js 0.186.1 (plain), troika-three-text 0.52.5, React 18.3.1, Vite 8, Tailwind 4, Vitest 5.

**Spec:** `mall-navigation/docs/superpowers/specs/2026-10-11-toy-3d-design.md`

## Global Constraints

- No new npm dependencies, no GLB / texture downloads, no CDN, no network calls except same-origin static files.
- Meaning colours stay unlit and exact: route, rings, markers, pins, sign faces and their text, labels, bays.
- `NoToneMapping` (renderer default); light intensities keep a white sun-facing roof at about 1.0.
- Idle = 0 frames; shadows are re-rendered only on scene changes, never on pure camera moves.
- Budgets: scene3d ≤ 60 KiB, engine3d ≤ 220 KiB, lazy total ≤ 260 KiB, first screen ≤ 110 KiB (report before raising).
- Every UI text ≥ 4.5:1 on its panel; primaries ≥ 56 px; nothing tappable < 44 px; RTL mirrors; SIMULATION always shown.
- `?style=storm` and `?style=classic` keep their 3D looks; default is `toy`.
- One headless browser at a time (8 GB RAM laptop).

```js
/**
 * 3D quality level (spec 3.2): 'showcase' = soft shadows + pixel ratio up to 2; 'light' = no shadows, pixel ratio up to
 * 1.5. Pure and outside src/engine, so the first screen can call it without pulling in the 3D chunk.
 * @param {{ urlParam?: string|null, deviceMemory?: number, cores?: number, saveData?: boolean }} p
 * @returns {'showcase'|'light'}
 */
export function pickQuality({ urlParam, deviceMemory, cores, saveData } = {}) {
  if (urlParam === 'showcase' || urlParam === 'light') return urlParam
  if (saveData) return 'light'
  if (Number.isFinite(deviceMemory) && deviceMemory < 4) return 'light'
  if (Number.isFinite(cores) && cores <= 4) return 'light'
  return 'showcase'
}
```

- Produces: `new MeshBuilder(registry, { rise?, bevel?: number, lit?: boolean })`.

```js
// constructor
this.bevel = Math.max(0, opts.bevel ?? 0)
this.lit = !!opts.lit

// prism(): replace the top-face line and the side loop
prism(footprint, h0, h1, topKey, sideKey, opts = {}) {
  const poly = ensureCCW(footprint)
  let bv = opts.top === false ? 0 : this.bevel
  if (bv > 0) {
    let minEdge = Infinity
    for (let i = 0; i < poly.length; i++) minEdge = Math.min(minEdge, Math.hypot(poly[(i + 1) % poly.length][0] - poly[i][0], poly[(i + 1) % poly.length][1] - poly[i][1]))
    bv = Math.min(bv, minEdge * 0.3, (h1 - h0) * 0.3)
    if (bv < 0.005 || !isConvexPoly(poly)) bv = 0
  }
  const inner = bv > 0 ? insetPolygon(poly, bv) : poly
  if (opts.top !== false) this.flat(inner, h1, topKey)
  if (opts.bottom) this.flat(poly, h0, opts.bottom, { down: true })
  for (let i = 0; i < poly.length; i++) {
    const p0 = poly[i]
    const p1 = poly[(i + 1) % poly.length]
    const dx = p1[0] - p0[0]
    const dy = p1[1] - p0[1]
    const l = Math.hypot(dx, dy)
    if (l < 1e-6) continue
    const out = [dy / l, -dx / l]
    this.vquad(p0, p1, h0, h1 - bv, sideKey, out, { ao: opts.ao, shade: opts.sideShade, unlit: opts.unlit })
    if (bv > 0) {
      // sloped band from the outer edge at h1 - bv up to the inset edge at h1 (top colour, lit by the sun)
      const q0 = inner[i]
      const q1 = inner[(i + 1) % inner.length]
      const s = 0.5 * (1 + wallShade(out[0], out[1]))
      const a = this.v(p0[0], p0[1], h1 - bv, topKey, s)
      const b = this.v(p1[0], p1[1], h1 - bv, topKey, s)
      const c = this.v(q1[0], q1[1], h1, topKey, s)
      const d = this.v(q0[0], q0[1], h1, topKey, s)
      this.triN(a, b, c, out[0], 1, -out[1])
      this.triN(a, c, d, out[0], 1, -out[1])
    }
  }
}
```

  plus module-level helpers:

```js
function isConvexPoly(p) {
  for (let i = 0; i < p.length; i++) {
    const a = p[i], b = p[(i + 1) % p.length], c = p[(i + 2) % p.length]
    if ((b[0] - a[0]) * (c[1] - b[1]) - (b[1] - a[1]) * (c[0] - b[0]) < -1e-9) return false
  }
  return true
}
/** Inset a convex CCW polygon by d (miter offset of every edge toward the inside). */
function insetPolygon(p, d) {
  const n = p.length
  const out = []
  for (let i = 0; i < n; i++) {
    const a = p[(i - 1 + n) % n], b = p[i], c = p[(i + 1) % n]
    const e1 = [b[0] - a[0], b[1] - a[1]], e2 = [c[0] - b[0], c[1] - b[1]]
    const l1 = Math.hypot(e1[0], e1[1]) || 1, l2 = Math.hypot(e2[0], e2[1]) || 1
    const n1 = [-e1[1] / l1, e1[0] / l1], n2 = [-e2[1] / l2, e2[0] / l2] // inward normals of a CCW polygon
    const m = [n1[0] + n2[0], n1[1] + n2[1]]
    const ml = Math.hypot(m[0], m[1]) || 1
    const k = d / Math.max(0.3, (m[0] / ml) * n1[0] + (m[1] / ml) * n1[1])
    out.push([b[0] + (m[0] / ml) * k, b[1] + (m[1] / ml) * k])
  }
  return out
}
```
